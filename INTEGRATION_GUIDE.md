User fills signup form\n   ↓\n2. Frontend validates input\n   ↓\n3. POST /api/auth/register\n   ↓\n4. Backend validates input (email, password length)\n   ↓\n5. Backend checks if user exists\n   ↓\n6. Backend hashes password with bcryptjs\n   ↓\n7. Backend creates user in MongoDB\n   ↓\n8. Backend generates JWT token\n   ↓\n9. Frontend receives token\n   ↓\n10. Frontend stores token in localStorage\n   ↓\n11. User redirected to dashboard\n```\n\n### Article Creation Flow\n```\n1. Authenticated user navigates to create article\n   ↓\n2. User fills form (title, content, category)\n   ↓\n3. Frontend validates input\n   ↓\n4. Frontend sends POST /api/articles with Bearer token\n   ↓\n5. Backend validates JWT token\n   ↓\n6. Backend validates input fields\n   ↓\n7. Backend creates article in MongoDB\n   ↓\n8. Backend returns article with author info\n   ↓\n9. Frontend displays success message\n   ↓\n10. User redirected to article view\n```\n\n### Get Joke Flow\n```\n1. Frontend requests /api/jokes/random\n   ↓\n2. Backend calls external API (jokes.one or chucknorris.io)\n   ↓\n3. Backend parses and formats response\n   ↓\n4.
